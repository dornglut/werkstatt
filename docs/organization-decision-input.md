## Accepted organization outcome

- Werkstatt is authorized as a bounded human-first application experiment.
- ADR 0003 remains current and its proportionality, protected-branch, read-only-validation, and authoring-tool-independence findings remain binding.
- revision-bound derived assistance and bounded operational execution state are permitted when they do not become parallel project authority;
- the `application` repository profile is accepted;
- human-only proof precedes agent integration;
- workspace and policy safety precede delegated execution;
- automatic issue selection, merge, multi-agent operation, and provider-neutral publication remain unauthorized.
